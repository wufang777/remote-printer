# macOS 打印文件发送端设计

## 目标

提供独立的 macOS 原生发送端 App，让用户手动选择一个 PDF/JPG/JPEG/PNG 文件，选择本地中转站中已注册的打印设备及其同步打印机，然后将任务提交给现有远程打印控制台。

## 范围

- 平台：macOS 14 及以上，SwiftUI。
- 第一版只支持一次选择一个文件并手动发送。
- 默认中转站为 `http://127.0.0.1:17880`；不支持远程或公网中转站。
- 中文 Aurora 明亮科技感 UI，默认窗口 1100×760。
- 支持展示提交后的任务编号和状态；不直接调用系统打印机。

## 中转站扩展接口

- `GET /sender/devices`：返回 `{ "devices": [{ "deviceId", "deviceName" }] }`。
- `GET /sender/devices/:deviceId/printers`：返回 `{ "printers": [{ "name", "isOnline", "isDefault" }] }`。
- 没有设备时返回空数组；未知设备返回 404。

## App 交互

1. 启动后请求中转站健康状态和设备列表；不可用时显示红色“中转站未连接”。
2. 用户点击“选择文件”，选取受支持文件。文件名显示在表单中，支持预览和删除。
3. 选择目标设备后加载打印机列表，默认选中设备默认打印机；离线打印机不可选择。
4. 点击“发送到远程打印”，以 multipart/form-data 调用 `POST /sender/jobs`。
5. 成功后显示任务 ID，在最近任务卡显示 `queued`；每 3 秒查询 `GET /sender/jobs/:taskId`，直到 `succeeded`、`failed` 或 `cancelled`。

## 客户端组件

- `RelaySenderClient`：封装 HTTP 健康、设备、打印机、上传与任务查询。
- `SenderState`：SwiftUI 可观察状态，负责文件选择、目标选择、发送/轮询和用户可读错误。
- `SenderView`：Aurora UI；不含网络或文件业务逻辑。
- `PrintSenderApp`：AppKit 启动器与窗口配置。

## 安全与限制

- 基础 URL 固定为回环地址；拒绝任意非 `127.0.0.1:17880` 地址。
- 上传前客户端和中转站都限制文件类型与 25 MB 大小。
- 使用 security-scoped 文件访问，只在上传时读取文件，不复制到发送端持久化目录。
- 不保存设备令牌、打印机凭证或文件内容。

## 验收

1. 中转站自动化测试覆盖设备/打印机只读接口。
2. Swift 单元测试覆盖回环 URL 验证、提交状态与发送失败提示。
3. 打开 App 后可选文件、选择设备/打印机、提交并显示任务编号。
4. 已打开的远程打印控制台在 10 秒内领取该任务；发送端状态随后更新。

## 非目标

- 不支持批量文件、拖拽、文件夹监控、账号登录和 Windows 版发送端。
- 不替代本地业务软件 HTTP 调用接口。
