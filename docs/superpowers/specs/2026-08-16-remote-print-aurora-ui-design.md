# Remote Print Aurora UI Design

## Goal

将 macOS 远程打印客户端的当前功能界面改造成明亮、未来科技感的 Aurora Control 视觉，同时保留本地文件打印、接入配置、任务预览、确认/静默打印的全部现有功能。

## Scope

- 平台：macOS 14 及以上。
- 视觉：浅蓝白基础、蓝青极光渐变、半透明玻璃卡片、柔和状态发光。
- 尺寸：默认窗口由 720×640 提升至 1440×900；正文、按钮和任务操作区的可点击高度不低于 44 pt。
- 文案：保持简体中文。
- 功能：不改变现有打印、预览和本地配置的行为。

## Layout

### 顶部导航

顶部固定为 72 pt 高的品牌栏。左侧显示渐变打印图标、名称“远程打印控制台”和“本机设备 · 实时任务通道”。右侧显示在线状态胶囊、设备名称和齿轮配置入口。在线状态使用青绿色圆点和轻微外发光。

### 主仪表区

首屏使用两列布局：左列占约 64%，为“创建打印任务”玻璃卡片；右列占约 36%，上下显示“设备状态”和“今日任务”两张摘要卡片。创建任务卡片包含内容类型、目标打印机、处理方式、文件选择、预览按钮及主操作“发送任务”。

### 任务区

任务区位于仪表区下方，使用独立玻璃容器。每条任务使用最小 76 pt 高的圆角行，按“状态图标 / 文件和目标 / 状态说明 / 操作”排列。待确认任务提供预览、确认、取消；其他带文件任务提供预览。状态色固定为：完成青绿、打印中蓝色、等待确认橙色、失败或取消红色。

### 文件预览

预览采用独立弹窗。标题栏展示文件名及“− / 100% / + / 关闭”操作。PDF 通过 PDFKit 缩放，图片通过可缩放滚动视图缩放；范围为 25% 至 400%。

## Visual Tokens

- 背景：`#F5F9FF` 至 `#ECF5FF` 渐变。
- 主渐变：`#2675FF` 至 `#35C8F7`。
- 强调发光：主渐变的 20% 不透明度、18 pt 模糊。
- 玻璃卡片：白色 72% 不透明度、14 pt 背景模糊、1 pt `#DCE9FF` 描边、20 pt 圆角。
- 主标题：28 pt semibold；区块标题：20 pt semibold；正文：16 pt；辅助文字：14 pt。
- 主按钮：44 pt 最小高度，12 pt 圆角，白色粗体文字。

## Data and State Rules

- 无打印机时禁用“发送任务”，并维持现有提示。
- 未选文件时禁用“预览所选文件”和“发送任务”。
- 文件预览不修改任务状态。
- 远程任务下载到本地缓存后，以相同的 `fileURL` 路径显示预览和打印，不另建预览分支。
- 设置仍通过右上角齿轮打开，配置字段和本机持久化方式保持不变。

## Acceptance Criteria

1. App 首次打开即展示 Aurora 控制台布局，默认窗口尺寸为 1440×900。
2. 所有主要操作可通过中文标签识别，并满足 44 pt 最小点击高度。
3. 本地 PDF 和图片可选择、预览、缩放、关闭，并能继续发送打印。
4. 确认模式与静默模式状态流转维持现有自动测试覆盖。
5. 接入配置弹窗仍可保存 HTTPS API 地址、设备名称、注册码和默认打印方式。
6. 所有 RemotePrintCore 自动测试通过；App 可构建并从 `.app` 启动。
